## Project

Kanban Project: an MVP of a Kanban-style project management application, built as a web app.

The repository was empty when this file was written. Update the Commands and Architecture sections once the `frontend` app is scaffolded.

## Business requirements

- Single board only.
- The board has 5 fixed columns. Columns can be renamed, but not added or removed.
- Each card has a title and details only.
- Drag and drop to move cards between columns.
- Add a new card to a column; delete an existing card.
- No other functionality: no archive, no search/filter. Keep it simple.
- The priority is a slick, professional, gorgeous UI/UX with very simple features.
- The app opens with dummy data populated for the single board.

## Technical details

- Modern Next.js app, client rendered.
- The Next.js app lives in the `frontend` subdirectory.
- No persistence (state is in memory only, so the dummy data returns on reload).
- No user management for the MVP.
- Use popular libraries.
- As simple as possible, but with an elegant UI.

## Commands

Run from `frontend/`:

```bash
npm install
npm run dev                      # http://localhost:3000
npm run build
npm run lint
npm test                         # vitest run
npx vitest run src/lib/board.test.ts -t "moves a card"   # single test
```

`.claude/launch.json` defines a `frontend` dev-server entry for the in-app browser preview.

## Architecture

- `frontend/` is a Next.js App Router app (TypeScript, Tailwind v4). `frontend/AGENTS.md` warns that this Next.js version differs from older ones; check `frontend/node_modules/next/dist/docs/` before using unfamiliar APIs.
- All board state lives in one `useReducer` in `src/components/Board.tsx`, driven by the pure `boardReducer` in `src/lib/board.ts` (actions: `renameColumn`, `addCard`, `deleteCard`, `moveCard`). The dummy data is `initialBoard` in the same file. Keep the reducer free of side effects (card ids are generated by the caller).
- Drag and drop uses `@dnd-kit`. `Board` owns the `DndContext`. `onDragOver` moves a card across columns live, and `onDragEnd` reorders within a column. Each `Column` is both a droppable (so empty columns accept drops) and a `SortableContext`; cards are `useSortable` items.
- Palette colors are Tailwind theme tokens in `src/app/globals.css` (`bg-page`, `bg-surface`, `text-ink`, `text-muted`, `border-line`, `bg-accent`, `bg-blush`, `bg-beige`, `border-rose`). Use these rather than hex values.
- Tests: `vitest.config.mts` (jsdom, `@` alias to `src`). Only the reducer is covered; drag and drop was verified manually in the browser.
